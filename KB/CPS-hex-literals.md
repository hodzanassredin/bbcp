# Hex-литералы в DevCPS (сканер компилятора)

Источник: Dev/Mod/CPS.odc, PROCEDURE Number (txt-экспорта нет, читать через
`odcey text Dev/Mod/CPS.odc`).

- суффикс `H` — 32-битный hex, <= 8 значащих цифр; 8 цифр и старшая > 7 ->
  отрицательный INTEGER (two's complement);
- суффикс `L` — 64-битный hex, <= 16 значащих цифр; 16 цифр и старшая > 7 ->
  отрицательный LONGINT;
- суффикс `S` — 32-битный hex float (SHORTREAL), `R` — 64-битный hex float;
- литерал обязан начинаться с ЦИФРЫ 0-9: `0C000000000000000L` — ок,
  `C000000000000000L` — сканер читает как идентификатор -> err 0
  "undeclared identifier". Лидирующие нули не считаются значащими цифрами;
- `10000000000H` (9 цифр) -> err 203 "number too large" — для 64-битных
  констант использовать суффикс L;
- десятичные константы до 2^63-1 принимаются (int64), 2^63 и выше -> err 203;
  MIN(LONGINT) писать как `8000000000000000L` или `-9223372036854775807 - 1`.
